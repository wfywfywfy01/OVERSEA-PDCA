# VERTU 全球国家合伙人简历打分评判模型 v2.0（试跑版）

> 适用对象：海外国家合伙人 / 储备顾问候选人简历预审。
> v2 相对 v1 的完善点：① 每个维度给出可操作的评分锚点与证据示例；② 引入证据等级 V/S/N，区分「可核验战绩」与「简历自述」；③ 增加一票否决红线；④ 增加同分排序规则；⑤ 增加试跑期校准机制。

## 一、五维打分（总分 10 分，阈值不变：≥5 分通过初筛）

### 1. 海外本地资源网络（2 分）
| 得分 | 锚点 |
|---|---|
| 2 | 目标国居住/深耕 ≥3 年，且能列出 ≥3 条本地资源：政商华人圈关系、商会/侨团任职、核心供应链联系人、可直接触达的 HNWI 客户名单 |
| 1 | 目标国居住 1–3 年或高频出差，有基础人脉，但以自述为主、可核验资源 <3 条 |
| 0 | 无当地驻留、无人脉、无本地资源证据 |

### 2. 行业与客群对口经验（2 分）
| 得分 | 锚点 |
|---|---|
| 2 | 奢侈品/名表珠宝/豪车销售管理，或 3C 科技大厂出海（华为/小米/传音/大疆等）区域负责人经历 |
| 1 | 传统 3C 外贸、跨境电商，或高端服务业（私人银行、高端移民/留学、游艇公务机、高端医疗）销售背景 |
| 0 | 无相关销售或出海背景 |

> v2 补充：高端服务业与 HNWI 客群高度重叠，纳入 1 分锚点（v1 未覆盖）。

### 3. 渠道开拓与商务谈判（2 分）
| 得分 | 锚点 |
|---|---|
| 2 | 主导过千万级渠道盘（年销售额/渠道体量），有签约本土经销商、进驻高端商场/专柜、大宗政商采购或企业礼品定制的落地战绩（能给出客户名+金额+时间） |
| 1 | 具备百万级大单拿下经验或区域渠道拓展经历 |
| 0 | 仅有基础执行/跟单，无商务开拓 |

### 4. 跨文化与语言能力（2 分）
| 得分 | 锚点 |
|---|---|
| 2 | 目标国官方语言精通/流利，可独立商务谈判；或英语流利且有本地资源背书 |
| 1 | 具备基础工作商务英语，可书面沟通，谈判仍需翻译支持 |
| 0 | 无法独立进行外语交流 |

### 5. 创业自驱与狼性自驱（2 分）
| 得分 | 锚点 |
|---|---|
| 2 | 有真实创业/合伙人经历，或明确表态以战功换取国家全盘权益、接受低底薪+高分成试跑 |
| 1 | 具备一定进取心，但要求保底薪酬或有明显打工思维残留 |
| 0 | 严重依赖底薪、朝九晚五打工人心态 |

## 二、证据等级（每条评分必须标注）

- **V（可核验）**：LinkedIn 档案、公司任职证明、合同/订单、客户名单、媒体报道、商会任职文件等可交叉验证的材料。
- **S（自述）**：仅简历描述或口头表达，尚未验证。
- **N（无）**：无任何证据。

> 规则：得分 ≥1 的维度若证据等级为 N，需降 1 分并在打分卡中标注「待核实」。

## 三、一票否决红线（触发任意一条 → 直接不予准入）

1. 简历造假或诚信问题（学历/经历/战绩不实）。
2. 与 VERTU 现有渠道冲突，或受竞业限制、原雇主机密约束。
3. 目标国无合法居留/工作/经营资格。
4. 涉及政治敏感、制裁名单或负面舆情。
5. 过往渠道盘存在欠款纠纷、资金风险或重大违约记录。

## 四、准入结论与同分排序

- **总分 ≥5 且无红线**：通过初筛 → 发放试跑工具包，签署《海外储备顾问协议》，启动首单攻坚。
- **总分 <5 或触发红线**：不予准入 → 进入储备人才库持续培育。
- **同分排序（tie-break）**：① 维度 1+3「核心分」高者优先；② V 级证据数量多者优先；③ 维度 5 得分高者优先。

## 五、试跑阶段校准机制

- 打分结果在首单攻坚 **30/60/90 天**后回看实际战绩，回填校准表（见打分卡模板）。
- 若试跑期内发现 V 级证据被证伪 → 该候选人立即降级，并复盘打分偏差原因。
- 每 10 份简历做一次模型校准复盘：比较「初筛分」与「实际战绩」，修正锚点或阈值。

## 六、打分流程

1. 收简历 → 提取五维证据（原文摘录，标注 V/S/N）。
2. 红线扫描（第五条红线逐条核对）。
3. 五维打分 → 总分 → 结论。
4. 输出打分卡 + 待核实问题清单 + 下一步动作。
